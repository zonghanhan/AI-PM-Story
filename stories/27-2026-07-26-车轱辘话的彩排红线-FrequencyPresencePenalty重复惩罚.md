## 寓言故事

### 一、名册稳了，话却开始打转

Top-p 事故复盘过去十天，**商小言** 的夸大词投诉降下来了；**内小言** 同问十次，连礼貌尾巴都一致。林薇以为 **采样参数** 这一章可以翻篇。

周一早会，**修小言** 客户成功群里跳出张先生的一条语音，语气很冲：

**「你们小言是不是只会三句话？我拍滤芯照片问怎么换，它跟我说：请先断电，请先断电，请先断电——后面还接了一句：操作前务必断电。我车间师傅笑我一上午。」**

林薇拉日志：上岗剧本没动，检索片段是 **《X-200 滤芯更换 SOP》** 正文，内容本身 **确实三处强调断电**；Temperature **0.2**，Top-p **0.3**——都是 **保守组合**。她困惑：**「参数都稳了，怎么还像卡带？」**

小陈把同一次会话的 **生成 trace** 投屏。每一轮选下一个词时，模型对 **「断电」「务必」「操作前」** 的概率条 **并没有被压低**——旁边两栏参数亮着：

**Frequency Penalty：0**  
**Presence Penalty：0**

小字：**对已出现过的 token 施加惩罚，降低其再次被采样的概率。**

**「温度管敢不敢冒险，Top-p 管名册多长；这两个管的是 **刚说过的话，还要不要再讲**。」** 小陈说，**「现在全是 0，等于 **彩排时不划禁台词**——模型觉得 **下一句继续讲『断电』最顺嘴**，就会一路复读。」**

---

### 二、彩排厅里的两条红线

为了讲清楚，小陈把会议室白板改成 **排演厅**。

**「想象小言是一场即兴演讲。每说一个词，场务就在 **提词板** 上记一笔。Frequency Penalty 像 **数你说了几遍**——说得越多，这个词 **下一遍的『出场费』越贵**；Presence Penalty 像 **只要出现过就贴条**——**不管说几遍**，只要 **这个词已经在台上亮过相**，就 **整体降权**。」**

林薇问：**「听起来像一回事？」**

小陈摇头，在板上画了两列：

| | Frequency Penalty | Presence Penalty |
|---|-------------------|------------------|
| **记什么** | 这个词 **出现了几次** | 这个词 **有没有出现过** |
| **惩罚怎么涨** | **次数越多，罚得越狠** | **出现一次就罚，罚额相对固定** |
| **像什么** | 老师 **「这个词你说了五遍了」** | 主持人 **「这个话题讲过了，换新的」** |
| **过猛会怎样** | 仍可能 **换词复读**（「断电」→「切断电源」→「请切断电源」） | 容易 **硬拐话题**，**该重复的安全句** 也可能被压没 |

当晚他们在预发 **固定同一份 SOP 检索结果**，只改惩罚参数，让修小言 **生成更换步骤** 五遍：

| 配置 | 典型现象 |
|------|----------|
| **双 0** | **「请先断电」** 在段首、段中、段尾 **各出现一次**，还爱加 **「操作前务必断电」** |
| **Frequency 0.3，Presence 0** | 复读减少，但 **「断电」「电源」** 仍会 **换说法重复** |
| **Frequency 0.2，Presence 0.4** | 安全提示 **保留一次**，后续步骤 **不再三令五申** |
| **双 0.8** | 安全词被压太狠，出现 **「然后安装滤芯」** 直接开头——**漏了断电** |

林薇盯着最后一行：**「这不是 **越高压越安全**，是 **产品要在『提醒到位』和『别烦人』之间找区间**。」**

---

### 三、修小言要「提醒一次」，商小言要「别堆形容词」

同一周，**商小言** 运营阿梅也来敲门。

某美妆商家用标题工具批量生成 **「玻尿酸精华液」** 卖点，五条标题里 **「高品质」「深层补水」「温和不刺激」** 像 **复制粘贴** 换顺序。商家吐槽：**「不是夸大，是 **像同一个模板刷出来的**。」**

日志同样是 **Frequency / Presence 双 0**。小陈解释：**「营销场景里，模型爱用 **高频套话** 凑字数；没有惩罚，它就会 **把检索里的形容词反复端上桌**。」**

林薇在 **双轨** 文档里又加一页：

**标准 / 规范流程（多租户、强审计）**

| 环节 | 做什么 |
|------|--------|
| **参数组合** | **SOP/安全类**：低 Frequency + **中低 Presence**（关键句 **允许出现一次**）；**标题/文案**：**中 Frequency + 中 Presence**（压套话，不压核心卖点词） |
| **与温度/Top-p 分工** | 惩罚参数 **不替代** 低温短名册；四者 **成组落库、成组回滚** |
| **评测** | 固定集测 **同句重复率**、**n-gram 重复**、**安全句是否漏写**；文案测 **形容词堆叠** 与 **人工采纳率** |
| **剧本层** | System Prompt 写 **「安全提示只说一次」**；惩罚参数是 **兜底**，不是 **剧本偷懒的替身** |

**中小常用默认方案（星尘当前）**

- **接云 API**：多数厂商默认 **双 0**；修小言 SOP 接口 **frequency_penalty 0.1–0.3、presence_penalty 0.2–0.5**；商小言标题 **0.3–0.6** 区间试跑。  
- **前台不暴露英文名**，映射 **「简练 / 标准 / 铺陈」** 档——**铺陈档** 只给 **创意预发**。  
- **可暂缓**：与 **后处理去重** 联动——先 **参数**，再 **规则删连续重复句**；别一上来 **只靠正则砍句** 误伤安全提示。

张先生那单，他们把 **修小言 SOP 模板** 调成 **Frequency 0.2、Presence 0.35**，同题再生五遍：**「请先断电」** 稳定出现在 **第一步**，后面 **不再三连击**。张先生回了个 **「这次像人写的」**——林薇截图贴进 **参数组合卡** 的 **「用户原话」** 栏。

---

### 四、剧本写了「只说一次」，还要不要拧旋钮？

复盘会上，阿梅问：**「System Prompt 里已经写了 **『安全提示不要重复』**，还要调惩罚吗？」**

小陈：**「剧本是 **软约束**，模型有时仍会 **图顺口**；惩罚是 **采样时的硬降权**。两个 **叠用** 更稳——但 **剧本不能因此缺位**，否则惩罚过高会 **把该说的安全句也压没**。」**

大刘补了一句工程侧真相：**「有些开源栈对 **中英文分词** 的惩罚粒度不一致；**『断电』** 和 **『断』+『电』** 可能被当成不同 token。评测要看 **真实用户会话**，别只在英文 Playground 里验。」**

林薇把 **常见误区** 写在白板底：

1. **双 0 不是「中性默认值」，是「允许复读」**  
2. **惩罚过高 ≠ 更专业**，可能 **漏安全步、文案变短变怪**  
3. **和 Temperature / Top-p 不是替代关系**，是 **同一管道里的下一组阀门**  
4. **「车轱辘话」有时来自检索片段本身重复**——先查 **RAG 切片**，再拧惩罚

---

### 五、接近结尾：禁台词不是禁言，是换节奏

又一周，修小言 **SOP 生成** 的 **重复投诉** 降了 **七成**；商小言标题 **「高品质×5」** 的截图 **少了一半**。配置台帮助文档 **参数组合卡** 多了两行：

| 场景 | Frequency | Presence | 产品备注 |
|------|-----------|----------|----------|
| 维修 SOP | 低 | 中低 | 安全句 **留一次**，别三连 |
| 商品标题 | 中 | 中 | 压套话，保留核心卖点词 |
| FAQ/制度 | 低 | 低 | 与低温短名册配；忌硬拐 |

林薇给新同学讲岗，指着 **Frequency / Presence**：

**「用户骂 **车轱辘话**，Often 不是模型 **不懂**，是 **下一句接龙时，重复最省力**。这两个参数就是告诉它：**刚说过的话，贵一点；亮过相的主题，别再来一遍。**」**

小陈把英文写在旁边：**Frequency Penalty，Presence Penalty。** 阿梅改文案参数前先问第二句：**「是 **SOP 怕漏句**，还是 **标题怕堆词**？」**——**两个场景，两套惩罚，别全站一个数。**

张先生在 **修小言** 群里又发了一张 **新滤芯照片**，这次附言：**「步骤清爽了。下次别让我师傅听三遍断电。」** 林薇把这句 **原样** 贴进 **评测固定集** 的 **通过标准** 旁：**产品成功的声音，有时候就是 **少复读一遍**。

## 概念正解

**Frequency Penalty（频率惩罚）** 与 **Presence Penalty（存在惩罚）**，是大语言模型在生成 **每一个词（Token）** 时，对 **已出现过的词** 施加的 **采样降权参数**：它们 **不改变模型知识**，而是在 **选下一个词** 时，让 **重复用词的概率变低**。**Frequency** 按 **该词已出现次数** 加重惩罚——**说得越多，越难再说**；**Presence** 按 **是否出现过** 惩罚——**只要说过一次，就整体降权**，更倾向 **换词、换角度**。**数值越高**，输出 **越少重复、越简练**，但也可能 **过度回避** 导致 **该强调的安全句被压没、文案变短变怪**。常与 **Temperature、Top-p** 配合使用；**不能替代** System Prompt、RAG 或后处理去重。

回扣故事：张先生听到的 **「请先断电」三连** 是 **双 0 → 模型沿最顺嘴路径复读**；修小言调 **低 Frequency + 中 Presence** 是 **安全句留一次、后续不堆**；商小言标题 **「高品质」堆砌** 是 **营销套话在无惩罚时反复采样**；漏断电案例说明 **惩罚过高会误伤必要重复**；剧本与惩罚 **叠用** 对应 **软约束 + 硬降权** 分工。

在 **AI 产品岗** 的典型场景：

| 场景 | 具体例子 |
|------|----------|
| **需求文档** | 写明 **Frequency / Presence 默认值、场景区间**；SOP 类写 **「关键安全句至少出现 1 次」** 与惩罚上限；与 temperature、top_p **成组配置** |
| **方案评审** | 问：投诉是 **真复读** 还是 **检索片段就重复**？惩罚拉高后 **安全句会不会消失**？中文 **分词粒度** 是否测过？ |
| **指标设计** | 同句重复率、n-gram 重复度、SOP **安全步覆盖率**、标题 **形容词密度**、参数变更后 **人工采纳率** |
| **跨团队沟通** | 对运营：**「简练档 = 略抬惩罚，不是砍字数」**；对算法：**「日志请四字参数成对落库」**；对客服：**「车轱辘话先查切片，再查惩罚」** |

## 类比锚定

**核心类比：彩排时的「禁台词」与「限次提醒」。** 导演不会禁止演员说话，但会在提词板上划 **「这句别连说三遍」**（Frequency），也会贴 **「这个话题讲过了，换下一段」**（Presence）；**Temperature / Top-p** 则是 **演员敢不敢即兴发挥、候选段子有多长**——四者 **同台不同工**。

| 你熟悉的 PM 经验 | Frequency / Presence 要素 |
|------------------|---------------------------|
| 发布会 **主持人提醒「这个词已说五次」** | **Frequency Penalty：次数越多，越难再说** |
| 议程 **「该话题已讨论，进入下一项」** | **Presence Penalty：出现过就降权，推动换角度** |
| 客服话术 **「关键免责声明念一遍即可」** | **低–中惩罚 + 剧本「只说一次」** |
| 海报文案 **同一形容词堆满版** | **无惩罚时模型爱重复高频套话** |
| 安全培训 **该强调的步骤不能因省话而删掉** | **惩罚过高会误伤必要重复——要测覆盖率** |

## 类比边界说明

### 一、概念核心要点

1. **Frequency 管「说了几遍」，Presence 管「有没有说过」**——前者 **越重复罚越狠**，后者 **一次就罚**，产品要 **分场景组合**。  
2. **默认双 0 等于允许顺嘴复读**；「车轱辘话」投诉时 **先查惩罚是否为 0**，再查剧本与检索。  
3. **惩罚过高有风险**：SOP **漏安全步**、文案 **变短变怪**、FAQ **硬拐话题**——必须 **固定集测覆盖率与重复率**。  
4. **与 Temperature、Top-p 叠在同一采样流程**，四参数 **成组设计、成组落库**，不要单拧一个当万能药。  
5. **不能替代 RAG 切片治理与后处理**：检索片段本身 **三处复制粘贴**，惩罚只能 **减轻症状**；**源头去重** 仍要做。

### 二、类比在哪里会失效

| 类比说法 | 失效点 | 更准确的理解 |
|----------|--------|--------------|
| 「像禁言，不让说某个词」 | 是 **降概率**，不是 **绝对禁止**；低概率仍可能被采样 | **减少重复倾向**，不保证 **零出现** |
| 「Presence 高就一定不重复」 | 模型可 **换同义词复读**（「断电」→「切断电源」） | 要配合 **Frequency** 与 **n-gram 后处理** |
| 「剧本写了别说两遍就够了」 | 剧本是 **软约束**，高温度或长名册时仍可能 **图顺口** | **剧本 + 惩罚 + 评测** 叠用 |
| 「英文 Playground 调好就能上线中文」 | **中英文 token 切分不同**，惩罚粒度 **可能不一致** | **用真实中文业务集回归** |
